# MediConnect — 5-page frontend website

A professional, responsive healthcare appointment website built with plain HTML, CSS, and JavaScript for a student case study.

## Pages
1. `index.html` — Home, specialties, service overview
2. `doctors.html` — Doctor directory with live search and filters
3. `appointments.html` — Demo appointment form with validation and local storage
4. `dashboard.html` — Sample health metrics, checklist, step counter, and saved demo appointments
5. `help.html` — FAQ accordion and demo contact form

## Run on your laptop
1. Download and extract `MediConnect.zip`.
2. Open the extracted `MediConnect` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

Recommended option: open the folder in Visual Studio Code and use the **Live Server** extension, then click **Go Live**. No npm install or build step is needed.

## Demo interactions
- All five pages share a responsive navigation menu.
- Doctor directory supports live text search, specialty filtering, and availability filtering.
- Booking form validates inputs and saves sample appointments in your browser's local storage.
- Dashboard displays saved appointments, lets you remove them, increments the demo step count, and updates wellness checklist progress.
- Help page includes expandable FAQs and a validated demo contact form.
- Demo bookings are visible in the same browser and browser profile only.

## Important
This is a frontend-only educational demo. It has no backend, authentication, database, real appointment system, or real medical data. Doctor profiles, prices, ratings, and health metrics are fictional examples. Do not enter sensitive personal or medical information. A live deployment would require a secure backend, privacy controls, and appropriate healthcare compliance.
